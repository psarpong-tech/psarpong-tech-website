# Psarpong Tech website — Version 1

This is the first front-end version of the Psarpong Tech website, built with HTML, CSS and vanilla JavaScript.

## Project structure

- `index.html` — Home page
- `styles/style.css` — shared visual styling and responsive layouts
- `scripts/main.js` — mobile navigation and current footer year
- `images/` — brand reference image(s)

## Run locally

1. Extract the ZIP.
2. Open the `psarpong-tech-website` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension if installed.

## Before publishing

- Add official email, WhatsApp, LinkedIn and GitHub links.
- Review every service description and only advertise services you are ready to deliver.
- Create the Services, Portfolio, About and Contact pages linked in the navigation. They are planned next, but are not included as completed pages in this first version.
- A plain HTML contact form does not send messages without a backend or a connected form service.
- Replace the temporary text-based PT mark with a finalized logo asset if you approve the proposed direction.
